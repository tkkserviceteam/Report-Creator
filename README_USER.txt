CPK Report Generator - Windows x64 Portable
===========================================

使用者端不需要安裝 Python、Tesseract OCR 或其他程式。

使用方式：
1. 將整個 CPK_Report_Generator 資料夾解壓縮到 Windows 電腦。
2. 雙擊 CPK_Report_Generator.exe。
3. 選擇 CPK1 圖片後，程式會嘗試 OCR 辨識六個 Cpk，並開啟預覽視窗讓你確認/修正。
4. 選擇 CPK2、Camera Up、Camera Down、sysdata.txt。
5. sysdata 會取最後 100 筆有效資料的前 6 欄填入報告。
6. Camera Up / Down 任一有提供時使用 CCD 範本；都沒有時使用 without CCD 範本。
7. 產生報告後請人工確認 Excel 版面與數值。

- Windows SmartScreen 第一次執行未簽章 EXE 時可能會顯示警告。
